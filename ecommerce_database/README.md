# Ecommerce Database

This container provides the data layer for the ecommerce_backend Flask service. It defines SQLAlchemy ORM models, database initialization utilities, and Alembic migrations.

## Features
- SQLAlchemy ORM models for users, products, categories, carts, orders, payments, addresses, and related tables.
- Alembic migrations to create schema.
- Initialization script to pre-seed demo data (optional).
- Environment variable-based configuration (no hardcoding).

## Folder Structure
- models/: SQLAlchemy ORM models
- db/: database engine and session management, initialization utilities
- migrations/: Alembic migration environment (autogenerated base and initial migration)
- requirements.txt: Python dependencies required for the database layer

## Environment Variables
Copy `.env.example` to `.env` and fill values. The orchestrator will provide actual secrets.

Required:
- DATABASE_URL: SQLAlchemy URL for your DB (e.g., `postgresql+psycopg2://USER:PASSWORD@HOST:PORT/DBNAME`)
- SQL_ECHO (optional): "true" or "false" to echo SQL statements.

NOTE: Do not commit actual secrets. Do not write the real `.env`. Only `.env.example` is provided.

## Usage
- Install deps: `pip install -r requirements.txt`
- Initialize Alembic (already configured) and apply migrations:
  - `alembic upgrade head`
- Seed demo data (optional):
  - `python -m db.init_db --seed`

## Integration with Backend
The `ecommerce_backend` should import models from `ecommerce_database.models` or connect to the same DATABASE_URL. Alternatively, this container can expose the models package for reuse.

## OpenAPI and Backend
This container only handles data layer and does not expose routes.
